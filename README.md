# Stochastic Simulations
This repository contains implementations of stochastic simulation methods for studying chemical reactions and biological processes.

## Projects

The repository is organized into separate branches, each focusing on a specific simulation project.

- **Gillespie Algorithm — Coupled Chemical Reactions:** Implementations reproducing results from the literature : "Exact Stochastic Simulation of Coupled Chemical Reactions."
DOI: https://doi.org/10.1021/j100540a008
- **Stochastic Gene Expression:** Simulation codes for exploring stochasticity in gene expression.
- **Nucleosome Dynamics:** Simulation codes for studying nucleosome dynamics using stochastic modeling approaches.

## Objectives

The primary objective of this repository is to reproduce published results, implement stochastic simulation models, and explore their applications to chemical and biological systems.

## Methods

The projects use Gillespie's stochastic simulation algorithm for each of the models.

## Repository Organization

Each project is maintained in its own branch, with the corresponding source code, documentation, and simulation results.
